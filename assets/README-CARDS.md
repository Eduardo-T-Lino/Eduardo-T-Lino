# Featured project cards — source assets

The four PNG cards in `project-cards/` are the visuals linked from the main README.

`project-logos/` contains the original image assets supplied for the four projects.
Each card uses the same solid background (`#171C26`), consistent layout, and a dark
very soft project-color shadow offset to the **bottom and right only**. Text is intentionally kept short.

To replace a logo or update a description/technology, modify the corresponding
source asset and regenerate the card. Keep card dimensions 1100 × 560 for consistent
layout, then replace the PNG in `project-cards/`.

The whole card is clickable through the `<a>` around its `<img>` in README.md.
